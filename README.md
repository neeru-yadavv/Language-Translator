# 🌍 Smart Language Translator

This is a web-based Language Translation Tool built using Flask and Google Translator API.

## 🚀 Features
- Multi-language translation
- Auto language detection
- Swap languages
- Copy translated text
- Text-to-speech (Speak feature)
- Clean UI

## 🛠 Tech Stack
- Python (Flask)
- HTML, CSS, JavaScript
- Deep Translator API

## ▶️ How to Run
1. Install dependencies:
   pip install flask deep-translator

2. Run the app:
   python app.py

3. Open browser:
   http://127.0.0.1:5000/
